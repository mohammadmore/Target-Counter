# پلتفرم صفحه‌های هدف تیمی و سازمانی

با یک ویزارد، صفحه‌ی زنده‌ی پیشرفت به سمت یک هدف بسازید؛ مثلاً «۶۰ میلیون امتیاز تا سفیر مروارید» یا «۵۰۰ مشتری تا پایان فصل».
هر صفحه ظاهر، متن، زبان و سبک نمایش مخصوص خودش را دارد و امتیازش به‌صورت زنده برای همه به‌روز می‌شود.

- **فرانت‌اند:** React 19 + Vite + Tailwind 4 (همه‌ی نمودارها با SVG خالص، فونت‌ها self-hosted)
- **بک‌اند:** `public/api.php` (PHP 7.4+ / MySQL) روی هاست cPanel

## آدرس‌ها

| آدرس | کاربرد |
|---|---|
| `./` | صفحه‌ی اصلی (هدفی که در داشبورد «صفحه‌ی اصلی» شده) |
| `./?g=<slug>` | صفحه‌ی یک هدف — `&lang=fa\|ar\|en` برای زبان |
| `./?g=<slug>&edit` | ثبت امتیاز (رمز ویرایشگر همان صفحه یا رمز مدیر) |
| `./?studio` | استودیو: داشبورد و ویزارد ساخت/طراحی صفحه‌ها (رمز مدیر) |

## ویزارد

۱. **اطلاعات پایه:** نام، عدد هدف، مقدار فعلی، آدرس، زبان‌ها (فارسی / عربی / انگلیسی)
۲. **سبک نمایش** (فقط یکی): گیج، حلقه، نوار پیشرفت، دماسنج، ظرف در حال پر شدن، مسیر و ایستگاه‌ها، شمارنده‌ی بزرگ، صد مروارید
۳. **ظاهر:** ۸ پالت آماده + ویرایش تک‌تک رنگ‌ها، ۱۰ فونت فارسی/عربی یا آپلود فونت دلخواه، گردی گوشه‌ها، پس‌زمینه (درخشش / گرادیان / ساده / تصویر + تیرگی)، ذرات معلق، لوگو
۴. **متن‌ها:** همه‌ی متن‌های صفحه برای هر زبان، با جای‌گذارهای `{target}` `{score}` `{remaining}` `{percent}` `{unit}`
۵. **امکانات و دسترسی:** کارت‌های آمار، جشن و کاغذ رنگی، پوستر، پخش دوباره، تغییر زبان، دکمه‌ی ثبت امتیاز، رمز ویرایشگر مخصوص همین صفحه
۶. **انتشار:** لینک اشتراک‌گذاری

در تمام مراحل، پیش‌نمایش زنده‌ی همان صفحه در قاب موبایل یا دسکتاپ نمایش داده می‌شود و با اسلایدر «پیشرفت آزمایشی» می‌توان حالت‌های مختلف، از جمله جشن رسیدن به هدف، را دید.

## دسترسی‌ها

- **مدیر پلتفرم** (رمز در `kiyan-config.php`): استودیو، ساخت/ویرایش/حذف صفحه‌ها، ثبت امتیاز همه‌ی صفحه‌ها
- **ویرایشگر یک صفحه** (رمز اختیاری هر صفحه، در ویزارد): فقط ثبت امتیاز همان صفحه؛ با تغییر رمز، نشست‌های قبلی باطل می‌شوند

## توسعه

```bash
bun install        # یا npm install
bun run dev        # http://localhost:3000
bun run test       # تست‌های واحد
bun run build      # typecheck + خروجی در dist/
```

در حالت `dev` (و پیش‌نمایش AI Studio) که PHP اجرا نمی‌شود، داده‌ها در localStorage مرورگر ذخیره می‌شوند
و ورود با هر رمزی پذیرفته می‌شود. **این رفتار فقط در حالت توسعه است** و در build نهایی وجود ندارد.

## نصب روی cPanel

1. `bun run build` و محتوای `dist/` (شامل `api.php` و `.htaccess`) را در پوشه‌ی سایت آپلود کنید.
2. `server/kiyan-config.example.php` را به نام `kiyan-config.php` کپی کنید، مقادیر را پر کنید و آن را
   **یک پوشه بالاتر از** پوشه‌ی سایت قرار دهید (مثلاً `/home/<user>/kiyan-config.php`).
3. جدول‌ها در اولین درخواست خودکار ساخته می‌شوند. اگر نسخه‌ی قبلی (جدول `kiyan_score`) نصب بوده،
   امتیاز و هدف فعلی‌اش با همان ظاهر قبلی به صفحه‌ی `kiyan` منتقل و صفحه‌ی اصلی می‌شود؛ لینک‌های قدیمی هم کار می‌کنند.
4. فایل‌های آپلودی (پس‌زمینه، لوگو، فونت) در پوشه‌ی `uploads/` کنار `api.php` ذخیره می‌شوند و اجرای PHP در آن بسته است.
   هنگام آپلود نسخه‌های بعدی، این پوشه را پاک نکنید.

> ⚠️ `kiyan-config.php` هرگز نباید commit شود (در `.gitignore` هست).

## API

| درخواست | دسترسی | بدنه |
|---|---|---|
| `GET api.php?goal=<slug>` | عمومی | — |
| `POST login` | — | `{"action":"login","password","goal"?}` |
| `POST update` | ویرایشگر/مدیر | `{"action":"update","goal","score","target"?}` |
| `POST list` / `get` / `save` / `delete` / `setDefault` | مدیر | ر.ک. توضیحات بالای `public/api.php` |
| `POST` multipart `upload` | مدیر | `action=upload`, `kind=image\|font`, `file` |

درخواست‌های احرازشده هدر `Authorization: Bearer <token>` دارند. توکن ۱۲ ساعت اعتبار دارد و
بعد از ۸ تلاش ناموفق ورود، آن IP به مدت ۱۵ دقیقه مسدود می‌شود.
