# پلتفرم صفحه‌های هدف تیمی و سازمانی

با یک ویزارد، صفحه‌ی زنده‌ی پیشرفت به سمت یک هدف بسازید؛ مثلاً «۶۰ میلیون امتیاز تا سفیر مروارید» یا «۵۰۰ مشتری تا پایان فصل».
هر صفحه ظاهر، متن، زبان و سبک نمایش مخصوص خودش را دارد و امتیازش به‌صورت زنده برای همه به‌روز می‌شود.

- **فرانت‌اند:** React 19 + Vite + Tailwind 4 (همه‌ی نمودارها با SVG خالص، فونت‌ها self-hosted)
- **بک‌اند:** `public/api.php` (PHP 7.4+ / MySQL) روی هاست cPanel

## آدرس‌ها

| آدرس | کاربرد |
|---|---|
| `./` | صفحه‌ی اصلی (هدفی که در داشبورد «صفحه‌ی اصلی» شده) |
| `./?g=<slug>` | صفحه‌ی یک هدف — `&lang=fa\|ar\|en` برای زبان |
| `./?g=<slug>&edit` | ثبت امتیاز (رمز ویرایشگر همان صفحه یا رمز مدیر) |
| `./?g=<slug>&draft=<token>` | پیش‌نمایش پیش‌نویس منتشرنشده (لینک را استودیو می‌سازد) |
| `./?studio` | استودیو: داشبورد و ویزارد ساخت/طراحی صفحه‌ها (رمز مدیر) |
| `./?studio&settings` | تنظیمات پایه: لوگوی استودیو (روشن/تاریک) و لینک‌های تماس کردیت |

## ویزارد

۱. **اطلاعات پایه:** نام، عدد هدف، مقدار فعلی، آدرس، زبان‌ها (فارسی / عربی / انگلیسی)
۲. **سبک نمایش** (فقط یکی): گیج، حلقه، نوار پیشرفت، دماسنج، ظرف در حال پر شدن، مسیر و ایستگاه‌ها، شمارنده‌ی بزرگ، صد مروارید
۳. **ظاهر:** حالت نمایش (فقط تاریک، فقط روشن، یا هر دو با دکمه‌ی خورشید/ماه برای بیننده)، ۸ پالت آماده که هر کدام نسخه‌ی تاریک و روشن هماهنگ دارند + ویرایش تک‌تک رنگ‌های هر حالت و ساخت خودکار حالت دیگر، ۱۰ فونت فارسی/عربی یا آپلود فونت دلخواه، گردی گوشه‌ها، پس‌زمینه (درخشش / گرادیان / ساده / تصویر + تیرگی)، ذرات معلق، لوگوی سازمان (اصلی + نسخه‌ی حالت تاریک) با انتخاب محل نمایش: بالای تیتر، پنل ثبت امتیاز، پوستر دانلودی، آیکن تب مرورگر
۴. **متن‌ها:** همه‌ی متن‌های صفحه برای هر زبان، با جای‌گذارهای `{target}` `{score}` `{remaining}` `{percent}` `{unit}`
۵. **امکانات و دسترسی:** کارت‌های آمار، جشن و کاغذ رنگی، پوستر، پخش دوباره، تغییر زبان، دکمه‌ی ثبت امتیاز، رمز ویرایشگر مخصوص همین صفحه
۶. **انتشار:** لینک اشتراک‌گذاری

- **پیش‌نویس و انتشار جدا هستند:** «ذخیره‌ی پیش‌نویس» صفحه‌ی عمومی را تغییر نمی‌دهد و لینک پیش‌نمایش برای تأیید می‌سازد؛ «انتشار» تغییرات را عمومی می‌کند. پیش‌نویس را می‌توان دور انداخت.
- **کار از دست نمی‌رود:** هر تغییر در همان مرورگر ذخیره می‌شود و بعد از بسته شدن تب قابل بازیابی است. اگر نشست وسط کار منقضی شود، رمز در یک پنجره پرسیده می‌شود و ذخیره‌ی نیمه‌کاره خودکار ادامه پیدا می‌کند.
- **ویزارد امتیاز را دست نمی‌زند** مگر اینکه مدیر صریحاً آن را تغییر دهد (و در آن صورت اگر کسی در این فاصله امتیاز ثبت کرده باشد، هشدار می‌دهد).
- **هشدارها:** متن‌های ترجمه‌نشده در زبان‌های فعال، و رنگ‌هایی که خوانایی کافی ندارند (با دکمه‌ی اصلاح خودکار).
- **تغییر آدرس صفحه** لینک‌های قبلی را خراب نمی‌کند؛ آدرس قدیمی خودکار به آدرس جدید می‌رود.

در تمام مراحل، پیش‌نمایش زنده‌ی همان صفحه در قاب موبایل یا دسکتاپ نمایش داده می‌شود و با اسلایدر «پیشرفت آزمایشی» می‌توان حالت‌های مختلف، از جمله جشن رسیدن به هدف، را دید.

## حالت روشن / تاریک

- **صفحه‌های هدف:** اگر صفحه «هر دو» باشد، بازدیدکننده ابتدا حالت تنظیم‌شده‌ی دستگاهش را می‌بیند و با دکمه‌ی خورشید/ماه عوض می‌کند (انتخابش روی همان دستگاه به خاطر سپرده می‌شود). پنل ثبت امتیاز هم از همان حالت پیروی می‌کند. صفحه‌های تک‌حالته (مثل صفحه‌ی کیان) همیشه همان حالت را دارند.
- **استودیو:** ظاهر گلسمورفیسم با گرادیان بنفش/آبی/صورتی در دو نسخه‌ی تاریک و روشن (پاستلی)، با دکمه‌ی تغییر حالت در ورود، داشبورد، ویزارد و تنظیمات.
- پیکربندی‌های قدیمی (تک‌پالت) بدون تغییر ظاهر منتقل می‌شوند و نسخه‌ی حالت دیگر برایشان آماده می‌شود.

## کردیت اسوا

پایین همه‌ی صفحه‌ها (صفحه‌ی هدف، ثبت امتیاز، صفحه‌های خطا و استودیو) یک کردیت شناور با دایره‌ی لوگوی اسوا نمایش داده می‌شود:

> Powered by Asva Studio
> توسعه یافته توسط شرکت داده پردازان اسوا

- با کلیک، لینک‌های تماس (وب‌سایت، ایمیل، تلفن، واتس‌اپ، تلگرام، اینستاگرام، لینکدین، لینک دلخواه) باز می‌شود. لینک‌ها فقط به‌صورت امن (`https`، `mailto`، `tel`) ساخته می‌شوند.
- لوگوی دایره در هر حالت از نسخه‌ی مخصوص همان حالت استفاده می‌کند (تنظیمات پایه)؛ بدون آپلود، نشان پیش‌فرض اسوا نمایش داده می‌شود.
- در پوستر دانلودی فقط «by Asva Studio» همراه لوگوی کوچک می‌آید.

## ثبت امتیاز (`?g=<slug>&edit`)

- حالت پیش‌فرض **«افزودن / کم کردن»**: مسئول تیم فقط مقدار امروز را وارد می‌کند (مثلاً +۱۵٬۰۰۰٬۰۰۰ با توضیح «شعبه‌ی ۲»)؛ جمع روی سرور و به‌صورت اتمی حساب می‌شود، پس ثبت هم‌زمان چند نفر هم درست است.
- حالت **«تنظیم عدد کل»** برای اصلاح؛ اگر کسی در این فاصله امتیاز را تغییر داده باشد، به‌جای بازنویسی هشدار می‌دهد.
- **تاریخچه‌ی ۳۰ ثبت آخر** با زمان، ثبت‌کننده و توضیح؛ آخرین ثبت قابل برگرداندن است.
- اعداد هنگام تایپ سه‌رقم‌سه‌رقم جدا می‌شوند؛ ارقام فارسی، عربی و لاتین پذیرفته می‌شوند.
- رابط به زبان همان صفحه (فارسی / عربی / انگلیسی) است و گزینه‌ی «این دستگاه را به خاطر بسپار» (۳۰ روز) دارد.
- دکمه‌ی ثبت امتیاز روی صفحه به‌صورت پیش‌فرض فقط در دستگاه‌هایی دیده می‌شود که قبلاً وارد شده‌اند؛ لینک مستقیم مسئول تیم در ویزارد (مرحله‌ی امکانات) قابل کپی است.

## دسترسی‌ها

- **مدیر پلتفرم** (رمز در `kiyan-config.php`): استودیو، ساخت/ویرایش/حذف صفحه‌ها، ثبت امتیاز همه‌ی صفحه‌ها
- **ویرایشگر یک صفحه** (رمز اختیاری هر صفحه، در ویزارد): فقط ثبت امتیاز همان صفحه — **تغییر هدف فقط از استودیو ممکن است**؛ با تغییر رمز، نشست‌های قبلی باطل می‌شوند

## توسعه

```bash
bun install        # یا npm install
bun run dev        # http://localhost:3000
bun run test       # تست‌های واحد
bun run build      # typecheck + خروجی در dist/
```

در حالت `dev` (و پیش‌نمایش AI Studio) که PHP اجرا نمی‌شود، داده‌ها در localStorage مرورگر ذخیره می‌شوند
و ورود با هر رمزی پذیرفته می‌شود. **این رفتار فقط در حالت توسعه است** و در build نهایی وجود ندارد.

## نصب روی cPanel

1. `bun run build` و محتوای `dist/` (شامل `api.php` و `.htaccess`) را در پوشه‌ی سایت آپلود کنید.
2. `server/kiyan-config.example.php` را به نام `kiyan-config.php` کپی کنید، مقادیر را پر کنید و آن را
   **یک پوشه بالاتر از** پوشه‌ی سایت قرار دهید (مثلاً `/home/<user>/kiyan-config.php`).
3. جدول‌ها در اولین درخواست خودکار ساخته و در به‌روزرسانی‌های بعدی خودکار مهاجرت داده می‌شوند (نسخه‌ی طرح در جدول `settings`). اگر نسخه‌ی قبلی (جدول `kiyan_score`) نصب بوده،
   امتیاز و هدف فعلی‌اش با همان ظاهر قبلی به صفحه‌ی `kiyan` منتقل و صفحه‌ی اصلی می‌شود؛ لینک‌های قدیمی هم کار می‌کنند.
4. فایل‌های آپلودی (پس‌زمینه، لوگو، فونت) در پوشه‌ی `uploads/` کنار `api.php` ذخیره می‌شوند و اجرای PHP در آن بسته است.
   هنگام آپلود نسخه‌های بعدی، این پوشه را پاک نکنید.

> ⚠️ `kiyan-config.php` هرگز نباید commit شود (در `.gitignore` هست).

## سرعت بارگذاری

- `index.html` قبل از دانلود برنامه، رنگ پس‌زمینه و یک لودر سبک نشان می‌دهد و درخواست داده را هم‌زمان با دانلود برنامه شروع می‌کند.
- بازدید دوباره از همان دستگاه، صفحه را بلافاصله با آخرین داده‌ی ذخیره‌شده نشان می‌دهد و بعد به‌روز می‌کند.
- هر صفحه فقط کد سبک نمایش خودش را دانلود می‌کند؛ پوستر، کاغذ رنگی، ویرایشگر و استودیو جدا و فقط در صورت نیاز بارگذاری می‌شوند.
- `.htaccess` فایل‌های ساخته‌شده (با نام هش‌دار) را یک سال در مرورگر کش می‌کند.

## API

| درخواست | دسترسی | بدنه |
|---|---|---|
| `GET api.php?goal=<slug>` | عمومی | — (پاسخ شامل `platform` برای کردیت است) |
| `GET api.php?platform` | عمومی | — |
| `POST login` | — | `{"action":"login","password","goal"?}` |
| `POST update` | ویرایشگر/مدیر | `{"action":"update","goal","mode":"add","amount","note"?}` یا `{"mode":"set","score","expectedScore"?,"note"?}` — `target` فقط از مدیر |
| `POST history` / `undo` | ویرایشگر/مدیر | `{"action":"history","goal"}` · `{"action":"undo","goal","entryId"}` |
| `POST list` / `get` / `save` (`publish`: پیش‌نویس یا انتشار) / `discardDraft` / `delete` / `setDefault` | مدیر | ر.ک. توضیحات بالای `public/api.php` |
| `POST savePlatform` | مدیر | `{"action":"savePlatform","profile":{"logoLight","logoDark","contacts":[{"type","value","label"}]}}` |
| `POST` multipart `upload` | مدیر | `action=upload`, `kind=image\|font`, `file` |

درخواست‌های احرازشده هدر `Authorization: Bearer <token>` دارند. توکن ۱۲ ساعت (یا با `remember` ۳۰ روز) اعتبار دارد و
بعد از ۸ تلاش ناموفق ورود، آن IP به مدت ۱۵ دقیقه مسدود می‌شود.
